# 🚀 SalesAI – Sales Prediction

**A Machine Learning-Based Sales Prediction and Business Intelligence Application**

SalesAI is a machine learning-based application developed to analyze retail sales data, predict sales, and provide business insights through an interactive dashboard.

## 📌 Project Overview

The project uses the `INDIA_RETAIL_DATA.xlsx` dataset containing **2,535 records** to perform sales analysis and build predictive machine learning models.

Multiple regression algorithms are evaluated to identify the best-performing model for sales prediction.

## 🎯 Project Objectives

- Analyze retail sales data.
- Predict sales using Machine Learning.
- Compare multiple regression algorithms.
- Generate meaningful business insights.
- Visualize important model features.
- Provide an interactive application for sales analysis and prediction.

## 📂 Dataset Information

| Parameter | Details |
|---|---|
| Dataset Name | INDIA_RETAIL_DATA.xlsx |
| Total Records | 2,535 |
| Prediction Target | Sales |
| File Format | Excel (.xlsx) |

## 🤖 Machine Learning Models

The following regression algorithms are used:

1. Gradient Boosting Regressor
2. Random Forest Regressor
3. Decision Tree Regressor
4. Linear Regression

**Best Performing Model:** Gradient Boosting Regressor

## 📊 Model Performance

The selected Gradient Boosting Regressor achieved the following reported performance:

| Evaluation Metric | Result |
|---|---:|
| R² Score | 94.96% |
| MAE | 150.10 |
| RMSE | 498.65 |

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/rushikesh61/SalesAI-Sales-Prediction.git
```

### 2. Navigate to the Project Folder

```bash
cd SalesAI-Sales-Prediction
```

### 3. Create a Virtual Environment (Optional)

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

### 5. Run the Application

```bash
streamlit run app.py
```

The Streamlit application will start locally in your browser.
